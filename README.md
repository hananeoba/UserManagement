# 📖 User Management

**User Management App**
is an app that is used to manage users. The application empowers users to:

- **Effortlessly explore users**: Navigate and discover the available users with ease.
- **Create new users**.

# 🛠Built With

## Technologies

This project was created with the following technologies:

- [Flutter](https://flutter.dev) - for cross-platform app development
- [MockApi.io](https://mockapi.io) - for backend API simulations
- **Clean Architecture** - for scalable and maintainable code structure
- **Test-Driven Development (TDD)** - to ensure code reliability and quality through extensive testing.

## Key Features

- **Responsiveness**: Provides a seamless experience across devices.
- **User Management**: Allows users to create and retrieve user data.
- **Clean Architecture**: Follows a modular and scalable structure to simplify development and maintenance.
- **Test-Driven Development (TDD)**: Built with rigorous unit tests to guarantee code robustness.

## 💻 Getting Started

To get a local copy up and running, follow these steps.

### Prerequisites

In order to run this project you need:

- Installation of Git
- Installation of Dart
- Installation of Flutter
- A working browser/phone/Android Emulator
- Internet connection
- A code editor like Visual Studio Code
- Any other tool you can think about

### Setup

Clone this repository to your desired folder:

```sh
  cd my-folder
  git clone https://github.com/hananeoba/UserManagement.git
```
